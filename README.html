Virtual Keyboard Simulator

A Windows desktop application: define custom keyboard key sequences (press time / release time / press duration), a draggable timeline, visual recording (auto-generates a sequence as you type), real key injection, a global emergency stop, and mod extension support (built-in Music mod: import a MIDI and auto-generate a performance sequence; Quick Input mod: timed text input and quick sequence arrangement with simultaneous-key support; a mod's UI can be injected directly into the main window's right-hand panel without any popup).

C# / .NET 4.0 WinForms Built-in csc · zero deps Win7 / 10 / 11 compatible

Project Overview

Features: full 104-key keyboard, step list (press/release timeline), draggable timeline table, visual recording, real key injection, auto-minimize on run, delay countdown, Ctrl+F9 global emergency stop, anti-mistouch switch, mod management.

Tech: compiled with the Windows built-in csc, zero third-party dependencies. Win7 needs .NET 4.0+; Win10/11 work out of the box.

Mod extension: at startup the app scans the mods\ folder next to the exe for *.dll and loads any mod that implements IVkMod. The built-in Music mod can import and play a MIDI; the Quick Input mod provides timed text input and quick sequence arrangement; a mod implementing IUiMod has its UI injected directly into the main window's right-hand panel, no popup needed.

Quick Start

  1. Launch

    Double-click「虚拟键盘模拟器.exe」.

  2. Build a sequence

    Click keys on the virtual keyboard → steps are added to the timeline automatically; or click「录制」and simply type on the real keyboard to auto-generate press/release sequences; drag in the timeline to adjust press/release times.

  3. Play

    Set speed% / loop / delay → click「运行」. The app auto-minimizes and injects the sequence into the target window; press Ctrl+F9 for a global emergency stop.

  4. Music performance

    「模组管理」→ Music mod →「操作/导入…」→ pick a MIDI → choose play mode / instrument / BPM → play.

  5. Quick input

    Once the Quick Input mod is loaded, its UI appears directly in the main window's right-hand「快捷输入」tab (no popup). ① On the timed-input tab, enter characters / total time (optional per-key duration) / snap → generate steps; or ② on the quick-arrangement tab, fill in key / duration / snap / wait row by row (use + to join multiple keys on one row for a simultaneous chord) → generate steps. Then bring the target app to the foreground and click「运行」.

Installation & Distribution

  • Installdouble-click setup.exe, choose a directory (defaults to the current user's programs directory, no admin needed); it automatically installs the main program + Music mod and creates a shortcut.
  • Silent installsetup.exe /install <directory>
  • UninstallControl Panel → Programs → Uninstall「虚拟键盘模拟器」, or setup.exe /uninstall
  • Portable distributionjust copy「虚拟键盘模拟器.exe」+ the mods\ folder and it works.

Development & Mod Extension

Modify the main program: edit the app\ source → recompile with the command below → overwrite the exe.

C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /optimize+ /out:虚拟键盘模拟器.exe /r:System.dll /r:System.Core.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll app\VkCore.cs app\Views.cs app\MainForm.cs app\ModApi.cs

Write a new mod: first read「模组开发\模组开发手册.md」→ follow「示例模组 AutoEnterMod.cs」to write code → compile with「模组开发\编译模组.ps1」→ drop the .dll into mods\ → restart the app → load and verify via「模组管理」.

Modify the Quick Input mod: edit「模组开发\快捷输入模组 QuickInputMod.cs」→ compile with「模组开发\编译快捷输入模组.ps1」→ restart the app; after logic changes run「工具\_checkmod.exe」for regression checks.

Inject a mod UI directly into the main program: implement IUiMod (UiTitle/UiContent); after loading it automatically appears as a right-hand tab (no「操作/导入…」popup) and is removed automatically on unload. The mod panel uses a dark, borderless style, auto-shrinks on narrow windows without covering the main UI, and has a collapse/expand button on its right edge for temporarily hiding it. See「模组开发\模组开发手册.md」3.6.
