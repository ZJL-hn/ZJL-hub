## 1. 模组是什么

模组是一个 `.dll` 文件，里面用 C# 实现了一个 `IVkMod` 接口。应用启动（或你在 “模组” 窗口点 “载入扩展”）时会：



1. 用 `Assembly.LoadFrom` 加载该 dll；

2. 找到实现了 `IVkMod` 的类并实例化；

3. 调用 `Initialize(IVkContext ctx)` 把 “上下文” 交给你；

4. 之后你的模组就能通过 `ctx` 读写步骤、注入按键、订阅事件。

**一句话：模组 = 实现&#x20;**`IVkMod`**&#x20;的一个 C# 类 + 编译出的 dll。**

### 2.2 系统兼容性（Win7 / 10 / 11）

应用与模组**统一以 .NET Framework 4.0 为目标**（编译器 `v4.0.30319` 即 .NET 4.0 CLR，exe 和模组 dll 都按它编译），因此在以下系统上均可用：

- **Windows 11**：预装 .NET Framework 4.8（向下兼容 4.0），开箱即用
- **Windows 10**：预装 .NET Framework 4.8，开箱即用
- **Windows 7（含 SP1）**：需已安装 .NET Framework 4.0 或更高（一般经 Windows Update 安装；若未装会提示），装上后即可运行

兼容性要点（写模组时务必遵守）：

1. **模组只能用 .NET Framework 4.0 可用的 API。** 别使用需要 4.5+ 的类型/特性（如 `async/await`、`System.Threading.Tasks` 的某些重载、`String.IsNullOrWhiteSpace` 等 4.0 已有的大多可用，但以 4.0 为准）。若用到高版本 API，在只装了 4.0 的 Win7 上会直接运行失败。
2. **产物为 AnyCPU**，同时兼容 32 位 / 64 位系统，无需区分。
3. 应用使用的系统 API（`RegisterHotKey`、`keybd_event`、`MapVirtualKey`、`timeBeginPeriod`、`GetForegroundWindow`、`SetWindowsHookEx` 等）均为 Win7 起就存在的经典接口，三系统通用。
4. Win7 无高 DPI 虚拟化，界面按系统缩放正常显示；Win10/11 高 DPI 下窗口以逻辑尺寸呈现，属正常。
5. 判断兼容性最简单的方式：**用与主程序相同的 `csc`（v4.0.30319）编译模组**，并只在 Win7 环境下实测一次即可。

## 3. 接口速查

### 3.1 你要实现的接口 `IVkMod`



```
public interface IVkMod
{
    string Name { get; }          // 模组名，显示在“模组”列表
    string Description { get; }   // 一句话说明
    void Initialize(IVkContext ctx);  // 应用注入上下文，在此订阅事件/初始化
    void Dispose();               // 应用退出/卸载时调用，记得退订事件
}
```

### 3.2 应用给你的接口 `IVkContext`



```
public interface IVkContext
{
    string ModDir { get; }                    // 模组目录（主程序 \mods）
    IList<KeyStep> Steps { get; }             // 当前步骤列表（可遍历）
    void AddStep(string key, int press, int release); // 追加一步（自动分配Id+排序+刷新）
    void RemoveStep(KeyStep st);              // 删除指定步骤
    void ClearSteps();                        // 清空全部步骤
    void InjectKeys(string combo);            // 立即按下再松开组合键，如 "ctrl+c"
    void SetStatus(string msg);               // 写状态栏
    void SetKeyNameMapper(Func<string,string> mapper); // 设置键名映射器：点击/录制时转换键名（见 3.4）
    event Action<KeyStep> StepAdded;          // 有步骤被添加
    event Action<KeyStep> StepRemoved;        // 有步骤被删除
    event Action PlayStarted;                 // 播放开始
    event Action PlayEnded;                   // 播放结束（含急停）
    void AddModUi(string title, Control content);  // 把模组界面作为新标签页注入主程序右侧面板（无需弹窗）；返回承载标签页
    void RemoveModUi(Control content);             // 卸载时移除已注入的界面
}
```

### 3.4 键名映射器（按键翻译类模组）

音乐模组这类“按键翻译”模组，需要把用户在虚拟键盘上点击、或录制到的键名改写成别的键再注入。调用 `SetKeyNameMapper` 传入一个转换函数，应用在**点击键盘**和**录制**时都会用它对键名做转换：

```csharp
ctx.SetKeyNameMapper(delegate(string key)
{
    if (key == "q") return "c"; // q → 高音 do（C）
    return key;                 // 其余键保持原样
});
```

规则：函数返回的字符串就是**最终注入的键名**；返回 `null` 表示“不转换、保持原键”。应用对每个键名独立调用，不影响未命中的键。转换在录制和点击两处都生效，所以点击 q 后“按键”输入框会直接显示 `c`，录制时按下 q 也会记录为 `c`。

### 3.5 可操作模组（可选）`ICommandMod`

需要“导入文件/触发一个动作”的模组（如音乐模组导入 MIDI 谱），可额外实现 `ICommandMod`，让“模组管理”窗口出现一个“操作/导入…”按钮，点击时调用你实现的 `OnCommand`：

```csharp
public class MyMod : IVkMod, ICommandMod
{
    // IVkMod 成员同前 …
    public void OnCommand(IVkContext ctx)   // 用户点“操作/导入…”时触发
    {
        using (var d = new System.Windows.Forms.OpenFileDialog())
        {
            d.Filter = "MIDI (*.mid)|*.mid";
            if (d.ShowDialog() != DialogResult.OK) return;
            // …读取并解析文件，用 ctx.AddStep 生成步骤，用 ctx.SetStatus 提示 …
        }
    }
}
```

注意：实现 `ICommandMod` 的模组在“模组管理”窗口被选中后，“操作/导入…”按钮才对该模组生效。

### 3.6 UI 注入模组（可选）`IUiMod`

需要“界面直接显示在主程序里、不想弹窗”的模组（如快捷输入模组），可额外实现 `IUiMod`。加载器在 `Initialize` 之后会自动把 `UiContent` 控件作为**右侧新标签页**注入主程序主界面；卸载模组时自动移除并隐藏面板，无需点“操作/导入…”：

```csharp
public class MyMod : IVkMod, IUiMod
{
    private Control _panel;
    // IVkMod 成员同前 …
    public string UiTitle { get { return "我的界面"; } }   // 注入页的标签标题
    public Control UiContent { get { return _panel; } }     // 要注入的控件（Initialize 里建好）

    public void Initialize(IVkContext ctx)
    {
        _panel = new MyPanel(ctx);          // 建好你的控件（UserControl 等）
        ctx.SetStatus("模组已载入：界面已在右侧“我的界面”页");
    }

    public void Dispose() { if (_panel != null) { _panel.Dispose(); _panel = null; } }
}
```

要点：

- `Initialize` 在 UI 线程执行，可直接创建控件；`UiContent` 必须非 null。
- 若还实现 `ICommandMod`，界面既注入右侧面板，也保留“操作/导入…”弹窗备用通道（同一控件可复用）。
- 主程序右侧面板宽度约 420 逻辑像素（窗口偏窄时自动收缩、保证主界面不被遮挡；右缘有缩起/展开按钮，可临时收起模组栏；面板为深色自绘、无白框），控件建议用 `Dock=Fill` + 内部 `AutoScroll` 自适应高度。
- 旧版模组（只实现 `IVkMod`/`ICommandMod`）不受影响：**`IVkContext` 新成员只允许追加到接口末尾**，已编译模组的方法槽位不会移位。

### 3.3 步骤对象 `KeyStep`



```
public class KeyStep
{
    public int Id;          // 应用分配的编号，模组不要自己设
    public string KeyName;  // 键名，如 "a" 或 "ctrl+c"
    public int PressTime;   // 按下时刻（毫秒，绝对时间）
    public int ReleaseTime; // 松开时刻（毫秒，绝对时间）
    public int Duration { get; }   // ReleaseTime - PressTime
    public string[] KeyTokens { get; } // KeyName 按 '+' 拆分后的数组
}
```

using VkSim;

public class HelloMod : IVkMod
{

## 5. 进阶：一个 “完整能力” 示例

下面这个模组同时用到：读写步骤、注入按键、订阅三个事件、状态栏反馈、释放时退订。可直接照抄学习。



```
using System;
using VkSim;

public class DemoMod : IVkMod
{
    public string Name { get { return "演示模组"; } }
    public string Description { get { return "演示：事件订阅/增删步骤/注入按键"; } }
    private IVkContext _ctx;
    private KeyStep _marker;   // 记录我们自己加的步骤，便于删除

    public void Initialize(IVkContext ctx)
    {
        _ctx = ctx;

        // 1) 读写步骤：清空后加两条
        ctx.ClearSteps();
        ctx.AddStep("enter", 0, 200);
        ctx.AddStep("tab", 250, 300);
        ctx.SetStatus("演示模组已载入，序列已重置为 Enter+Tab");

        // 2) 订阅事件
        ctx.StepAdded  += OnAdded;   // 注意：我们自己的 AddStep 也会触发 StepAdded
        ctx.PlayStarted += OnPlayStart;
        ctx.PlayEnded   += OnPlayEnd;
    }

    private void OnAdded(KeyStep st)
    {
        _ctx.SetStatus("检测到新增步骤: " + st.KeyName + " " + st.PressTime + "ms");
    }

    private void OnPlayStart()
    {
        _ctx.SetStatus("开始播放——现在可以按 Ctrl+F9 全局急停");
    }

    private void OnPlayEnd()
    {
        // 播放结束后追加一个步骤（此刻 playing=false，允许修改）
        _ctx.AddStep("f9", 0, 100);
        _ctx.SetStatus("播放结束，已追加 F9");
    }

    public void Dispose()
    {
        if (_ctx != null)
        {
            _ctx.StepAdded -= OnAdded;
            _ctx.PlayStarted -= OnPlayStart;
            _ctx.PlayEnded -= OnPlayEnd;
        }
    }
}
```

## 6. 支持的全部键名（KeyMap）

以下字符串可直接用作 `AddStep` / `InjectKeys` 的键名。组合键用 `+` 连接，如 `"ctrl+shift+a"`。

**功能键：** `escape`(`esc`) · `f1`…`f12` · `printscreen` · `scrolllock` · `pause`

**主键区：** `` ` `` · `1`…`0` · `-` · `=` · `backspace` · `tab` · `q`…`p` · `[` · `]` · `\` · `capslock` · `a`…`l` · `;` · `'` · `enter` · `shift`(`leftshift`/`rightshift`) · `z`…`m` · `,` · `.` · `/`

**修饰与系统：** `ctrl`(`leftctrl`/`rightctrl`) · `win`(`leftwin`/`rightwin`) · `alt`(`leftalt`/`rightalt`) · `space` · `menu`

**编辑区：** `insert`(`ins`) · `home` · `pageup`(`pgup`) · `delete`(`del`) · `end` · `pagedown`(`pgdn`) · `up` · `down` · `left` · `right`

**数字小键盘：** `numlock` · `num/` · `num*` · `num-` · `num+` · `numenter` · `num0`…`num9` · `num.`

> 大小写不敏感；
>
> `AddStep`
>
>  里键名会原样存入 
>
> `KeyName`
>
>  用于显示，播放时按上面的映射注入真实按键。

## 7. 装载与测试流程



1. **写代码**：在 `mods\` 里新建 `.cs`，实现 `IVkMod`
2. **编译**：用 `编译模组.ps1`（或手动 csc 命令）产出 `.dll`
3. **放置**：把 `.dll` 放进主程序同目录的 `mods\`（自动扫描该目录）
4. **载入**：重启应用；或运行时在工具栏点 “模组”→“载入扩展…” 选 dll
5. **查看**：“模组”窗口会列出名称 + 说明；模组的 `SetStatus` 会写状态栏
6. **卸载**：“模组”窗口点 “卸载全部”，或直接把 dll 移出 `mods\`

> 已有现成脚本 
>
> `mods\编译模组.ps1`
>
> ，双击运行即可把同目录的 
>
> `AutoEnterMod.cs`
>
>  编译成 dll，可直接复制改成你自己的模组。

## 8. 规则与限制（务必遵守）



1. **播放中不能改步骤。** `AddStep` 在 `playing == true` 时会被忽略。想 “播放结束时加点” 请订阅 `PlayEnded`（此时已允许）。

2. **事件默认在 UI 线程触发。** `StepAdded/StepRemoved/PlayStarted/PlayEnded` 的回调不要做长时间阻塞（会卡界面）；重活请另开线程，并只通过 `ctx` 的方法回写。

3. `InjectKeys`**&#x20;会真实发系统按键**，作用在**当前前台窗口**上。别在你自己不想要的目标上乱发。

4. `Id`**&#x20;由应用分配。** 别手工设置 `KeyStep.Id`，用 `ctx.AddStep` 自动处理。

5. **直接改&#x20;**`ctx.Steps`**&#x20;不会自动刷新界面。** 增删请用 `AddStep/RemoveStep/ClearSteps`（会自动排序 + 刷新）；只是读取遍历 `Steps` 没问题。

6. **Dispose 必须退订事件**（`-=`），否则可能重复触发。

7. **模组即代码**，能注入按键 / 读系统，只加载你信任来源的 dll。

8. 编译时引用主程序 exe（`/r:虚拟键盘模拟器.exe`）即可拿到 `IVkMod/IVkContext/KeyStep`，**不需要**额外复制任何文件。

9. **`IVkContext` 新成员只能追加到接口末尾**，不能插到中间——否则会让已编译模组的接口方法槽位移位、调用错位而失效。本手册 3.6 的 `AddModUi/RemoveModUi` 即按此规则追加在事件之后。

## 9. 常见问题

**Q：载入报 “该文件未包含模组实现”？**

你的类没实现 `IVkMod`，或没写 `: IVkMod`；或类不是 public 的。确认类为 `public class ... : IVkMod` 且不是 abstract。

**Q：载入报异常（如找不到类型 / 版本冲突）？**

多半是引用了别的 .NET 版本或漏引用。模组只依赖 `System.dll`、`System.Core.dll` 和主 exe 里的接口，别引其它。

**Q：状态栏一直显示我上一次 SetStatus 的话？**

每次 `SetStatus` 会覆盖；播放结束应用会写 “执行完成” 等系统信息，正常。

**Q：怎么让模组 “每次播放都自动执行某个动作”？**

订阅 `ctx.PlayStarted`（动作不能改步骤）或 `ctx.PlayEnded`（可以改步骤）。

**Q：想要跟用户交互（弹窗 / 读文件）？**

模组是普通 C#，可以用 `System.Windows.Forms.MessageBox`、`OpenFileDialog` 等，随你怎么写。

**Q：想让模组界面直接显示在主程序里（不弹窗）？**

实现 `IUiMod`（见 3.6）：`UiTitle` 给标签标题，`UiContent` 返回在 `Initialize` 里建好的控件。加载器载入后自动把该控件作为右侧新标签页注入主界面，卸载时自动移除。
